===== nn::util::BinaryFileHeader =====

offset | size | type    | description
-------+------+---------+-----------------------------------------------------------
0x00   | 0x08 | char[8] | signature ("VFXB    ")
0x08   | 0x01 | u8      | unused
0x09   | 0x01 | u8      | graphics API version (4 for odyssey)
0x0a   | 0x02 | u16     | format version (22 for odyssey)
0x0c   | 0x02 | u16     | byte order mark (0xFEFF for big endian, 0xFFFE for little endian)
0x0e   | 0x01 | u8      | alignment (actual alignment = 1 << this value)
0x0f   | 0x01 | u8      | target address size
0x10   | 0x04 | u32     | offset of filename string relative to this header
0x14   | 0x02 | u16     | is relocated
0x16   | 0x02 | u16     | offset of first block relative to this header
0x18   | 0x04 | u32     | offset of relocation table relative to this header
0x1c   | 0x04 | u32     | file size
0x20   |      |         | end

===== nn::vfx::detail::BinaryData =====
all offsets are relative to the the start of this block's header
offset | size | type    | description
-------+------+---------+-----------------------------------------------------------
0x00   | 0x04 | char[4] | signature
0x04   | 0x04 | u32     | block size
0x08   | 0x04 | u32     | offset to first child block
0x0c   | 0x04 | u32     | offset to next sibling block
0x10   | 0x04 | u32     | offset to first attribute (?)
0x14   | 0x04 | u32     | offset to data
0x18   | 0x04 | u32     | unused
0x1c   | 0x02 | u16     | child count
0x1e   | 0x02 | u16     | padding
0x20   |      |         | end

ESTA - Emitter Set Array
  children:
    ESET - Emitter Set
    children:
      EMTR - Emitter (attributes)
PRMA - Primitive Array
  children:
    PRIM - Primitive (unclear what this is yet, non g3d primitives)
GRTF - Texture File - binary data points to bntx
  child:
    GTNT - Unknown
G3PR - G3D Primtives - binary data points to bfres
  child:
    GRNT - Unknown
GRSN - G3D Shaders - binary data points to bnsh
  child:
    GRSC - G3D Compute Shaders - binary data points to bnsh
